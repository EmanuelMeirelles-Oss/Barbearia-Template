## ✨ Sobre o Projeto

O **Vintage Barbers** é um template de front-end puro (HTML, CSS, JS) feito para estabelecimentos de beleza masculina que desejam transmitir uma imagem clássica e premium através da internet. A interface utiliza as melhores práticas de **Glassmorphism**, contrastes intensos e micro-interações dinâmicas para encantar o cliente desde o primeiro acesso.

A ideia principal é oferecer um fluxo de agendamento ágil, mostrando os profissionais, serviços e horários em um fluxo muito agradável.

## 🚀 Principais Features

- **Design Premium**: Uso de paleta de cores curada (Dark Mode + Dourado) e tipografia elegante (Playfair Display + Inter).
- **Efeito Glassmorphism**: Painéis translúcidos, desfocados e estéticos.
- **Sistema de Agendamento Visual**: Interface step-by-step pronta para ser integrada a um back-end.
- **100% Responsivo**: Otimizado para funcionar perfeitamente em telas de desktop, tablets e dispositivos móveis.
- **Micro-interações de UI**: Efeitos de hover brilhantes em botões e cards de serviço.

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação semântica do conteúdo.
- **CSS3 Vanilla**: Estilizações puras, CSS variáveis, Flexbox, Grid e animações (`backdrop-filter`).
- **JavaScript Vanilla**: Manipulação da DOM para a interface dinâmica de agendamento e navegação.
- **FontAwesome**: Ícones vetorizados.
- **Google Fonts**: Tipografias modernas.

## ⚙️ Como rodar localmente

1. Clone o repositório em sua máquina:
```bash
git clone https://github.com/SEU_USUARIO/barbearia-template.git
```
2. Abra a pasta do projeto:
```bash
cd barbearia-template
```
3. Abra o arquivo `index.html` em qualquer navegador web, ou utilize a extensão **Live Server** no VS Code para uma experiência de recarregamento automático.

## 💡 Próximos Passos (Integração de Backend)

Por ser um template focado em Front-end, o sistema de agendamento ainda está com dados mockados. Para tornar tudo funcional, você pode conectar esse projeto a ferramentas como:
- **Node.js + Express** (Para construir a API de agendamento)
- **Supabase ou Firebase** (Para banco de dados das reservas e profissionais)
- **n8n** (Para webhooks automáticos, como notificações no LinkedIn ou mensagens via WhatsApp para seus clientes!)
